# BrightLoop - Subscription Management & Recurring Billing Platform

BrightLoop is a unified subscription management and recurring billing web application designed to handle customer lifecycles, tiered product variants, subscription contracts, automated recurring invoicing, payment allocations, dynamic tax/discount calculations, and financial reporting.

## Monorepo Structure

- `client/`: React + TypeScript + Vite + Tailwind CSS frontend application
- `server/`: Node.js + Express + TypeScript + Prisma backend application
